# 文件区与取件

CodeCrate 内置两套文件共享能力：**公共文件区**（所有人可见）与**私人传递（取件码）**（仅凭码领取），配合**留言板**形成内网日常文件流转与反馈的完整闭环。

## 公共文件区

公共区适合「发给所有人」的文件：驱动包、工具合集、临时资料等。

### 上传步骤

1. 进入「公共区」页，在**公共区**标签下点击或拖拽选择文件；
2. 页面会显示已选文件名与大小，此时**不会立即上传**；
3. 填写备注（选填，例如「给测试组的驱动包」）；
4. 点击 **确认上传** 才会真正开始传输。

### 规则与限制

- 上传后**所有人可见**，请勿上传敏感或涉密文件；
- 默认保留 **7 天**，到期由系统自动删除（列表中会显示剩余有效期倒计时）；
- 单文件大小、扩展名黑名单、总配额由管理员在「系统设置 → 软件包与文件区」配置；
- 上传频率限制为每 IP 每 10 分钟 10 次。

### 搜索与下载

- 列表支持按**文件名或备注**搜索；
- 下载支持 HTTP Range 断点续传，大文件中断后可续传。

## 私人传递（取件码）

适合「发给某个人」的文件：文件不出现在公共列表中，只有拿到取件码的人能领取。

### 生成取件码

1. 在「公共区 → 私人传递」标签填写备注、有效期（默认 72 小时）、可选下载次数上限；
2. 取件码可自定义（4-16 位字母数字），留空则自动生成 8 位无歧义字符码；
3. 选择文件后点击 **生成取件码**，取件码**只展示一次**，请立即复制并告知对方。

### 领取文件

1. 对方打开「取件」页，输入取件码；
2. 显示文件名、大小与到期时间后即可下载；
3. 下载链接 15 分钟内有效，过期需重新取件；下载本身支持断点续传。

### 安全说明

- 取件码在服务端以 scrypt 哈希存储，泄露数据库也无法还原明文；
- 取件码兑换有频率限制（每 IP 每 15 分钟 20 次），防止暴力猜测；
- 管理员可随时在「文件区管理」**撤销、延期或删除**任意取件；
- 取件页不受前台访问码限制——**取件码本身就是凭证**，请勿外传。

## 留言板与评论

- 「留言板」是全站公共留言区，软件包详情内也有对应反馈区；
- 发表评论会**自动展示内网 IPv4**（管理员可开启脱敏显示为 `192.168.*.*`）；
- 支持两层回复：对回复再回复会拍平为「回复 @某人」；
- 管理员可置顶、删除评论（连带回复）。

## 管理员须知

- 「文件区管理」提供公共区与私人取件的完整管理权：搜索、延期、撤销、删除，并可见上传者 IP；
- 到期文件由系统每 30 分钟自动清理一次，同时写入审计日志（`file.expire`）；
- 建议开启总配额（例如 50 GB）与保留期，防止磁盘被占满；
- 所有设置在「系统设置 → 软件包与文件区」中调整，保存即生效。
